Core User Flow

1Open app → Sign-in sheet appears (dismissible)
↓
2Browse catalogue (guest) → Full catalogue across three feed tabs: every institution, all four content types
↓
3Tap Open Access item → Read + Download, no loan (no session needed)
↓
4Tap Subscription/Elite item → Access Gate sheet appears
↓
5Choose route: "Through my institution" (SSO) or "Personal account" (email)
↓
6Authenticate → Pending-intent store remembers tapped item
↓
7⭐ Returns to SAME item → Re-resolved access: Subscription→Read+Download, Elite→Read only, Not entitled→Subscribe (B2C) / Access Restricted (B2B)
↓
8Catalogue re-scopes → B2B: entitled + Open Access + Elite. B2C: Open Access
↓
9First tap borrows → Open Access and Subscription create a loan, then show Read + Download. Elite takes no copy, so never borrows.

Revised — v0.2. Steps 2 and 8 replace the v0.1 model in which the catalogue was never filtered by institution in any session state. The feed now has two scopes: full when logged out, B2B sees entitled + Open Access + Elite; B2C sees Open Access. Pending ratification by leadership (delivery plan L-2). Buy and Borrow are removed from the prototype; subscribe is added, and is B2C-only. wokay serve three separate OPDS endpoints, surfaced as three tabs rather than the single mixed list in the screen 01 mockup — merging would require cross-feed dedup, merged pagination and re-ranking three incomparable result sets. Pending ratification (delivery plan L-5).

resolveAccess Contract

resolveAccess(item, session) → {
  tier:    'open_access' | 'subscription' | 'elite',
  state:   'available' | 'requires_signin' | 'not_entitled' | 'no_seats',
  actions: ['read'] | ['read','download'] | ['borrow']
         | ['signin'] | ['subscribe'] | ['waitlist'] | []
}

// Every screen renders from state + actions only.
// No screen knows what a licence is.
//
// Elite, when entitled, resolves to ['read'] — never download.
// A loan is required for anything the user can take a copy of:
//   Open Access + Subscription -> ['borrow'] first, then ['read','download']
//   Elite -> ['read'] only. No copy taken, so no loan, ever.
//   Logged out + Open Access -> ['read','download']. No borrower to lend to.
// not_entitled → ['subscribe'] for B2C, [] for B2B (Access Restricted).
// Reachable only via pending intent — the signed-in feed contains
// no unentitled items.
